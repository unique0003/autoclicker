# Auto Clicker (Android)

แอปคลิก/ปัดหน้าจออัตโนมัติ เขียนด้วย Kotlin ไม่มี dependency ภายนอก ไม่ขอสิทธิ์อินเทอร์เน็ต

## Build
1. เปิดโฟลเดอร์นี้ด้วย Android Studio (Koala ขึ้นไป) แล้วรอ Gradle Sync
2. ต่อมือถือ (เปิด USB debugging) แล้วกด Run หรือ Build > Build APK(s)
   (ต้องใช้ Android 7.0 / API 24 ขึ้นไป)

## ติดตั้งและเปิดใช้
1. เปิดแอป > "เปิดบริการ Accessibility" > เลือก Auto Clicker > เปิด
2. Android 13+ ถ้าติดตั้งจากไฟล์ APK แล้วเปิดไม่ได้: ตั้งค่า > แอป > Auto Clicker > ⋮ > "อนุญาตการตั้งค่าที่ถูกจำกัด" แล้วลองใหม่
3. กลับมาที่แอป > "แสดงแผงควบคุมลอย"

## ปุ่มบนแผง
⠿ ลากย้ายแผง | ▶/⏸ เริ่ม/หยุด | ＋ เพิ่มจุดแตะ | ⇄ เพิ่มการปัด (A→B) | － ลบจุดล่าสุด | ⚙ ตั้งค่า | ✕ ปิดแผง

## ฟังก์ชัน
- หลายจุดทำงานตามลำดับ วนซ้ำ, แตะ / กดค้าง / ปัด
- ตั้งช่วงเวลา, สุ่มเวลาและตำแหน่งเล็กน้อย, จำนวนรอบ, หน่วงก่อนเริ่ม
- จำตำแหน่งจุดและค่าตั้งค่าไว้ในเครื่อง

## ความปลอดภัย
- ทำงานเมื่อกด ▶ เท่านั้น และมีเวลาสูงสุดบังคับเสมอ (ดีฟอลต์ 10 นาที, สูงสุด 6 ชม.)
- หยุดทันทีเมื่อ สลับแอป / ปิดหน้าจอ / เข้าหน้า Settings, ขอสิทธิ์, ตัวติดตั้งแอป, Play Store
- ช่วงเวลาขั้นต่ำ 50 ms; คลิกพลาดต่อเนื่อง 5 ครั้งหยุดเอง
- ไม่อ่านเนื้อหาหน้าจอ (canRetrieveWindowContent=false) ไม่มี INTERNET ไม่เก็บข้อมูลนอกเครื่อง
- อย่าใช้กับหน้าชำระเงิน/โอนเงิน/ยืนยันตัวตน และเช็กกฎของเกมก่อน (บางเกมแบนผู้ใช้ตัวช่วยคลิก)

ไฟล์หลัก: `app/src/main/java/com/example/autoclicker/ClickService.kt`
